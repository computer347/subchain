# subchain

Do US defence contract awards ripple down to the *listed suppliers* of the winning prime — and do incumbents that lose a recompete underperform?

Research study using only public data (USAspending sub-awards, DoD contract announcements, SEC EDGAR). See `SPEC.md` for the pre-registered hypotheses, data rules and decision criteria, and `PROGRESS.md` for status.

Status: Phase 0 (spec). Not investment advice.
